# Architecture Decision Records

Place accepted, rejected and superseded architecture/product/security decisions here as `ADR-NNNN-short-title.md`.

Use the root [`ADR_TEMPLATE.md`](../../ADR_TEMPLATE.md). Number records monotonically and link the requirements/specification sections they affect. Never silently overwrite a material decision; supersede it with a new ADR and include a migration plan when implementation has shipped.
