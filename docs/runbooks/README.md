# Operational Runbooks

Create one focused runbook per real operational procedure. The minimum set is listed in [`RELIABILITY_DEPLOYMENT.md`](../../RELIABILITY_DEPLOYMENT.md#9-runbooks-required-before-beta).

Each runbook must identify severity/trigger, decision owner, prerequisites, safe containment, diagnostics, commands/actions, expected output, rollback/recovery, verification, communication and escalation. Keep credentials out of examples. Test the steps in staging and record the last successful exercise.
