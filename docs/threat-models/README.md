# Threat Models

Use this directory for threat-model revisions tied to meaningful product releases or new trust boundaries.

The baseline security requirements are in [`AUTHORIZATION_SECURITY.md`](../../AUTHORIZATION_SECURITY.md). Each threat model should record assets, actors, trust boundaries, entry points, abuse cases, existing controls, residual risk, test coverage and owner. Update it for OAuth/session changes, new tenant data types, uploads, external integrations, platform support access, bot permission changes and privileged operational features.
